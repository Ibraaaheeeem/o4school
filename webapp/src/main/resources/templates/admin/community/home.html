📋 Bulk Import Data

Import multiple records at once using a single Excel file with separate sheets for each category.

📁 File Structure

Use a single Excel file (.xlsx) with at least one of the following sheets:

  • Sheet 1: Students
  • Sheet 2: Parents
  • Sheet 3: Staff

Each sheet must be named exactly as shown above and follow the format specified in the tabs below.

Student Import Format

📅 Date Format: DD/MM/YYYY (e.g., 15/05/2010)
ℹ️ Parent relationships, class assignments, and grade levels will be set up within the app after import.

Column Name Required Description Example
FirstName Yes Student's first name Ibrahim
LastName Yes Student's last name Musa
MiddleName No Student's middle name Aliyu
Gender Yes M or F M
DateOfBirth Yes Format: DD/MM/YYYY 15/05/2010
AdmissionNumber No Auto-generated if empty ADM/2024/001
Address No Residential address 123 Lagos Street, Kano

Parent Import Format

Column Name Required Description Example
FirstName Yes Parent's first name Fatima
LastName Yes Parent's last name Musa
Email Yes Unique email (used for login & linking) parent@example.com
PhoneNumber Yes Phone number with or without country code 08012345678
Address No Residential address 123 Lagos Street, Kano

Staff Import Format

📅 Date Format: DD/MM/YYYY (e.g., 10/01/2022)

Column Name Required Description Example
FirstName Yes Staff's first name Chioma
LastName Yes Staff's last name Okonkwo
Email Yes Unique email address teacher@school.com
PhoneNumber Yes Phone number 07098765432
Designation Yes Job title (e.g., Teacher, Bursar, Cleaner) Teacher
DateOfHire No Format: DD/MM/YYYY 10/01/2022
